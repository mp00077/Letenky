# Pravidla projektu

- Po každé dokončené změně doplňte do `changelog.md` aktuální datum a stručný český popis. Nejnovější data uvádějte nahoře; existující záznamy zachovejte.
- Distribuční build spouštějte pouze na výslovný pokyn uživatele. Úpravy zdrojů, generování UI pro vývoj a testy jsou povolené.
